# Source Fonts

These are the pre-built upstream fonts used as inputs to the Planetaire Mono build pipeline.

## B612 Mono Ligature Nerd Font

- **Source**: [carlosedp/b612](https://github.com/carlosedp/b612) fork
- **Version**: Latest from carlosedp (includes dotted zero, ligatures, Nerd Font patching)
- **Original**: B612 typeface by Intactile Design for Airbus (cockpit display font)
- **License**: OFL-1.1 + EPL-2.0 (see `licenses/B612-OFL.txt`, `licenses/EPL-2.0.html`)
- **Files**: `b612/B612MonoLigaNerdFont-{Regular,Bold,Italic,BoldItalic}.ttf`

## Hack Nerd Font

- **Source**: [ryanoasis/nerd-fonts](https://github.com/ryanoasis/nerd-fonts) patched Hack
- **Version**: v3.4.0 (from kerm reference build)
- **Original**: [Hack](https://github.com/source-foundry/Hack) by Source Foundry
- **License**: MIT (see `licenses/Hack-LICENSE.md`, `licenses/NerdFonts-LICENSE`)
- **Files**: `hack/HackNerdFont-{Regular,Bold,Italic,BoldItalic,ExtraBold,ExtraBoldItalic}.ttf`

The ExtraBold variants in `hack/` were generated by the prior kerm build using
FontForge's `changeWeight()` on the Bold variants.
