# Source Fonts

These are the pre-built upstream fonts used as inputs to the Planetaire Mono build
pipeline.

## B612 Mono

- **Source**: [polarsys/b612](https://github.com/polarsys/b612) (original)
- **Version**: 1.008
- **Origin**: B612 typeface by Intactile Design for Airbus (cockpit display font)
- **License**: OFL-1.1 and EPL-2.0 (see `licenses/B612-OFL.txt`,
  `licenses/EPL-2.0.html`)
- **Files**: `b612/B612Mono-{Regular,Bold,Italic,BoldItalic}.ttf`
- **Glyphs**: 590 per variant, UPM 2000

The ExtraBold and Medium variants (`B612Mono-ExtraBold*.ttf`, `B612Mono-Medium*.ttf`)
are generated by the Planetaire build pipeline from the Bold and Regular variants
respectively, using FontForge’s `changeWeight()`.

## Hack Nerd Font

- **Source**: [ryanoasis/nerd-fonts](https://github.com/ryanoasis/nerd-fonts) patched
  Hack
- **Version**: Hack 3.003, Nerd Fonts 3.3.0
- **Origin**: [Hack](https://github.com/source-foundry/Hack) by Source Foundry
- **License**: MIT (see `licenses/Hack-LICENSE.md`, `licenses/NerdFonts-LICENSE`)
- **Files**: `hack/HackNerdFont-{Regular,Bold,Italic,BoldItalic}.ttf`
- **Glyphs**: ~11,957 per variant (includes Nerd Font icons), UPM 2048

The ExtraBold and Medium variants (`HackNerdFont-ExtraBold*.ttf`,
`HackNerdFont-Medium*.ttf`) are generated by the Planetaire build pipeline from the Bold
and Regular variants respectively, using FontForge’s `changeWeight()`.
