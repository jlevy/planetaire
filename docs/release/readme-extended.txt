Planetaire Mono Extended

The full Planetaire Mono font: B612 letterforms, Hack punctuation and symbols, and
~12,000 Nerd Font icons plus Powerline glyphs. A superset of Planetaire Mono Text.

Contents:
  ttf/   TrueType fonts. Recommended for local install (terminals, editors, desktop
         apps). Double-click a .ttf to install, or copy the files into your OS font
         folder (macOS: ~/Library/Fonts; Linux: ~/.local/share/fonts then fc-cache -fv).
  web/   WOFF2 web fonts and planetaire-mono-extended.css for use via @font-face.

Recommended: for local and terminal use, install from ttf/. The web fonts here carry
the full icon set and are large; for websites, the lighter Planetaire Mono Text family
is usually the better choice.

Tip: map your terminal's bold to ExtraBold (weight 800) for the best contrast.
