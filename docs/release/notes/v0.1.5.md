**Planetaire Mono** — a beautiful, highly legible monospace font for terminals, editors, and agentic work.

Project links: [GitHub repo](https://github.com/jlevy/planetaire) · [README](https://github.com/jlevy/planetaire#readme) · [download and install instructions](https://github.com/jlevy/planetaire#download) · [web-font usage](https://github.com/jlevy/planetaire#web)

## Which package?

- **Planetaire Mono Extended** — the full font: all 10,000+ Nerd Font icons and Powerline glyphs (12,000+ total glyphs). Use this for terminals, editors, and coding (recommended for most local use).
- **Planetaire Mono Text** — a lightweight text family with no icons. Use this for the web, documents, and places where smaller files matter.

Each archive contains:

- **`ttf/`** — TrueType fonts for local install.
- **`web/`** — WOFF2 files plus ready `@font-face` CSS for browser use.
- **`README.txt`**, **`LICENSE`**, and **`licenses/`** — package notes and upstream license texts.

Extended is a superset of Text. Text TTFs include all 10 styles; Text web fonts ship a slim Regular/Bold unicode-range split for Latin, Greek, and Cyrillic, with optional italic CSS. Browsers fetch only the script ranges a page uses. Use the `.tar.xz` archives when possible; `.zip` is provided for Windows and tools that do not handle `.tar.xz`.

Verify downloads with `SHA256SUMS` from this release page.

## What's Changed

### New Features

- **International web subsets** — the Text web fonts now ship a Google Fonts-style unicode-range split (Latin, Latin Extended, Greek, Cyrillic, and Cyrillic Extended) with a Regular/Bold base stylesheet and an optional Regular/Bold italics stylesheet. Browsers fetch only the script ranges a page actually uses, so adding Greek or Cyrillic support does not grow the payload for Latin-only pages. The generated CSS also defines a `--planetaire-mono-text-font-stack` custom property backed by a metric-matched local fallback, keeping line height stable while `font-display: swap` loads the WOFF2.

### Improvements

- **Regenerated synthetic masters** — the intermediate Medium, SemiBold, and ExtraBold masters were rebuilt more cleanly (including a much leaner, correctly subset ExtraBold), refreshing glyph outlines consistently across the family.
- **Refreshed README and site** — tightened the B612 and Planetaire Mono background and the personal note, and moved the project site to [ojoshe.com/planetaire](https://ojoshe.com/planetaire/) with a new monospace font comparison page.

### Compatibility Notes

- **Reinstall for the refreshed outlines** — glyph outlines were regenerated this release, so reinstall the TTFs to pick them up. There are no family, style, weight, or filename changes, so terminal and editor configs do not need to change.
- **New Text web CSS layout** — the Text `web/` folder now uses per-range split WOFF2 files with a Regular/Bold base CSS (`planetaire-mono-text.css`) plus an optional `planetaire-mono-text-italics.css`. If you embedded the previous single Text stylesheet, switch to the new split CSS; the `--planetaire-mono-text-font-stack` custom property is the simplest entry point.
