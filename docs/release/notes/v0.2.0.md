**Planetaire Mono** is a beautiful, highly legible monospace font for terminals, editors, and agentic work.

Project links: [GitHub repo](https://github.com/jlevy/planetaire), [README](https://github.com/jlevy/planetaire#readme), [download and install instructions](https://github.com/jlevy/planetaire#download), [web-font usage](https://github.com/jlevy/planetaire#web), and a [monospace font comparison](https://ojoshe.com/planetaire/compare.html).

## Which Package?

- **Planetaire Mono Extended:** the full font, with all 10,000+ Nerd Font icons and Powerline glyphs (12,000+ total glyphs). Use this for terminals, editors, and coding (recommended for most local use).
- **Planetaire Mono Text:** a lightweight text family with no icons. Use this for the web, documents, and places where smaller files matter.

Each archive contains:

- **`ttf/`**: TrueType fonts for local install.
- **`web/`**: WOFF2 files plus ready `@font-face` CSS for browser use.
- **`README.txt`**, **`LICENSE`**, and **`licenses/`**: package notes and upstream license texts.

Extended is a superset of Text. Text TTFs include all 10 styles. Text web fonts ship a slim Regular/Bold unicode-range split for Latin, Greek, and Cyrillic, with optional italic CSS, so browsers fetch only the script ranges a page uses. Use the `.tar.xz` archives when possible; `.zip` is provided for Windows and tools that do not handle `.tar.xz`.

Verify downloads with `SHA256SUMS` from this release page.

## What's Changed

This release corrects the OS/2 metrics, which had been inherited unchanged from the Hack base font and described Hack's letters rather than the ones the fonts draw. No glyph outline or advance width changed. It is a minor version bump rather than a patch because the corrected metrics are visible to anything that sizes or lays out text from the table.

### Fixes

- **Corrected x-height, cap height, and average character width:** the build now measures these off the outlines it ships instead of carrying over the base font's values, so they stay right as the sources change. At 2000 units per em, `sxHeight` goes from 1094 to 1120-1130, `sCapHeight` from 1458-1460 to 1520-1525, and `xAvgCharWidth` from 1233-1240 to 1204, the true monospace cell. Consumers that size text from the table - CSS `font-size-adjust`, editor line boxes, font-manager previews - were sizing the base font rather than the one on screen, and are now correct. This is a metadata-only fix: compared against v0.1.5, no glyph bound and no advance width differs, on any of the ten faces of either family.
- **Vertical box no longer clips drawn ink:** the inherited `usWinAscent`/`usWinDescent` pair, 1901/483, was tighter than the ink the fonts actually draw, which reaches 1940/-560 and beyond. The pair is now one family-wide box covering the widest ink extents across the family, stamped identically on every face and on every split web subset cut from them, so weights and script subsets no longer disagree about it. See the line-spacing note below.

### Compatibility Notes

- **Reinstall for the corrected metrics:** the values live in the font files, so reinstall the TTFs or re-download the archives to pick them up. There are no family, style, weight, or filename changes, so terminal and editor configs do not need to change.
- **Line spacing on stacks that ignore USE_TYPO_METRICS:** browsers and any stack that honors the USE_TYPO_METRICS flag lay out from the `sTypo` metrics, which are unchanged at 1856/-472/0, or 1.164 em, so rendering there is identical. Stacks that ignore the flag - classic GDI, some Java/AWT paths, older Office - take default line spacing from `usWinAscent + usWinDescent` instead, and that box is now large enough to cover all drawn ink. On those stacks default line spacing grows from 1.192 em to 1.3915 em for Text (+16.7%) and to 1.4335 em for Extended (+20.3%). The extremes are not set by letters: the descent comes from four combining marks (U+0318, U+0319, U+031E, U+031F) and Extended's ascent from Nerd Font icon ink drawn above the em. If you use Planetaire Mono in one of those applications and had tuned line spacing by hand, check it after upgrading.
- **Re-pin web CDN links to `@v0.2.0`:** the documented web-font URLs are pinned to `cdn.jsdelivr.net/gh/jlevy/planetaire@v0.1.5/...`, and jsDelivr caches a versioned ref for a year. Pages embedding those URLs keep serving the v0.1.5 files with the old metrics until the links are re-pinned to `@v0.2.0`. The README and project site are re-pinned with this release; update your own copies of the pinned URLs. The unversioned `releases/latest/download/...` links need no change.
