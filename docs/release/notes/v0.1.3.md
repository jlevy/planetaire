**Planetaire Mono** — a beautiful, highly legible monospace font for terminals, editors, and agentic work.

## Which package?

- **Planetaire Mono Extended** — the full font: all ~12,000 Nerd Font icons and Powerline glyphs. Use this for terminals, editors, and coding (recommended for most local use).
- **Planetaire Mono Text** — a lightweight subset with no icons, so it is much smaller. Use this for the web and documents.

Each archive contains **`ttf/`** (TrueType, for local install) and **`web/`** (WOFF2 plus a ready `@font-face` stylesheet, for the web). Extended is a superset of Text. Both now ship **10 styles**: five weights — Regular, Medium, SemiBold, Bold, and ExtraBold — each with an italic.

See the [README](https://github.com/jlevy/planetaire#readme) for details and [install instructions](https://github.com/jlevy/planetaire#install).

## What's Changed

### New Features

- **SemiBold (600) weight** — a new SemiBold and SemiBold Italic sit between Medium and Bold, bringing both families to ten styles. SemiBold is treated as its own weight, not a Bold face, so it style-links and reports correctly.
- **Embedded license** — the SIL Open Font License copyright and license are now carried in the font name tables, and every archive bundles the upstream license texts (B612, Hack, Nerd Fonts) under `licenses/`.

### Improvements

- **Cleaner italics** — italic faces keep even stroke weights and use a slight overhang instead of condensing, so italic text matches the color and rhythm of the roman.
- **Refreshed specimen and README** — the type specimen is now version-stamped, and the README adds B612 research history, design notes, a size waterfall, and RFC 1 excerpts.
