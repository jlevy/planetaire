**Planetaire Mono** — a beautiful, highly legible monospace font for terminals, editors, and agentic work.

## Which package?

- **Planetaire Mono Extended** — the full font (TrueType): all ~12,000 Nerd Font icons and Powerline glyphs. Use this for terminals, editors, and coding.
- **Planetaire Mono Text** — a lightweight subset with no icons: TrueType plus WOFF2/WOFF web fonts and a ready `@font-face` stylesheet. Use this for the web and documents.

Both ship 8 weights (Regular through ExtraBold, with italics).

See the [README](https://github.com/jlevy/planetaire#readme) for details and [install instructions](https://github.com/jlevy/planetaire#install).
