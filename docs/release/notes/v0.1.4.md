**Planetaire Mono** — a beautiful, highly legible monospace font for terminals, editors, and agentic work.

## Which package?

- **Planetaire Mono Extended** — the full font: all 10,000+ Nerd Font icons and Powerline glyphs (12,000+ total glyphs). Use this for terminals, editors, and coding (recommended for most local use).
- **Planetaire Mono Text** — a lightweight subset with no icons, so it is much smaller. Use this for the web and documents.

Each archive contains **`ttf/`** (TrueType, for local install) and **`web/`** (WOFF2 plus a ready `@font-face` stylesheet, for the web). Extended is a superset of Text. Both ship **10 styles**: five weights — Regular, Medium, SemiBold, Bold, and ExtraBold — each with an italic.

See the [README](https://github.com/jlevy/planetaire#readme) for details and [download and install instructions](https://github.com/jlevy/planetaire#download).

## What's Changed

The fonts themselves are unchanged from v0.1.3; this release refreshes the specimen, the README, and the release tooling.

### Improvements

- **Redesigned type specimen** — a new title page, opened-up line height, a simplified color system, and oriented quotes; the full license now sits on its own page and the code specimen fits a single page.
- **Restructured README** — adds the Hack lineage and a note on its functional punctuation, explains the Planetaire Mono name, corrects the glyph and icon counts, and consolidates install guidance under Download while promoting the Terminal Configuration and Web sections.
- **Tag-pinned, two-step release process** — releases are cut with `make release`, which stamps the version into the specimen PDF and pins the README and site jsDelivr CDN links to the release tag so they stay byte-for-byte consistent.
